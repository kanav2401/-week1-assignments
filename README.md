# WeIntern – Week 1 Web Development Assignments

## About This Repository

This repository contains the three practical assignments completed as part of my Web Development Internship at WeIntern Pvt. Ltd.

The assignments focus on frontend development, responsive web design, CSS layouts, and animations using HTML, CSS, and JavaScript.

## Assignments

### 1. Professional Portfolio Website

A personal portfolio website designed to showcase my introduction, technical skills, projects, and contact information.

**Features:**
- Home, About, Projects, and Contact pages
- Responsive design for desktop and mobile devices
- Dark and light theme toggle
- Interactive navigation menu
- Project showcase section
- Contact form with frontend validation
- Smooth navigation and user interactions

**Technologies Used:** HTML5, CSS3, JavaScript

**Project Folder:** `portfolio-website/`

### 2. Business Landing Page – EstateVista

EstateVista is a premium real estate business landing page designed to showcase properties and real estate services in Mohali, Chandigarh, Panchkula, and nearby areas.

**Features:**
- Professional navigation bar
- Attractive hero section
- Property search functionality
- Property category filtering
- Featured property listings
- About Us section
- Real estate services section
- Why Choose Us section
- Contact form with validation
- Responsive desktop, tablet, and mobile layouts

**Technologies Used:** HTML5, CSS3, JavaScript

**Project Folder:** `business-landing-page/`

### 3. CSS Challenge – CSS Playground

A practical CSS project demonstrating modern layout techniques, responsive design, and animation effects.

**Features:**

**Flexbox Layout**
- Three testimonial cards arranged horizontally on desktop
- Vertical card arrangement on mobile
- Flexible widths and consistent spacing
- Interactive hover effects

**CSS Grid Layout**
- Six feature cards
- Responsive three-column desktop layout
- Two-column tablet layout
- Single-column mobile layout
- Consistent card styling and alignment

**CSS Animations**
- Button hover animation
- CSS loading spinner
- Card lift effect
- Fade-in content animation
- Smooth transitions and transformations

**Technologies Used:** HTML5, CSS3, JavaScript

**Project Folder:** `css-challenge/`

## How to Run the Projects

1. Clone or download this repository.
2. Open the repository folder in Visual Studio Code.
3. Select the project you want to run.
4. Open its `index.html` file using the Live Server extension.
5. The project will open in your default browser.

Each project can run independently.
