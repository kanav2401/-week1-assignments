This repository contains three practical frontend development assignments completed as part of the Web Development Internship at WeIntern Pvt. Ltd.

The projects demonstrate skills in semantic HTML, CSS styling, responsive web design, Flexbox, CSS Grid, animations, and professional frontend project organization.

## Assignment 1: Professional Portfolio Website

A personal portfolio website created to present my professional profile, technical skills, development projects, and contact information.

### Features
- Multi-page website with Home, About, Projects, and Contact pages
- Responsive desktop, tablet, and mobile layouts
- Dark and light theme toggle
- Interactive navigation
- Project showcase
- Contact form with frontend validation
- Consistent styling and typography

**Technologies:** HTML5, CSS3, JavaScript

**Project Directory:** `portfolio-website/`

**Live Demo:** [Open Portfolio Website](https://kanav2401.github.io/-week1-assignments/portfolio-website/)

## Assignment 2: Business Landing Page – EstateVista

EstateVista is a premium real estate landing page designed to present property listings and real estate services in Mohali, Chandigarh, Panchkula, and nearby areas.

### Features
- Professional navigation bar
- Hero section with property search
- Property listings and category filters
- Location, property type, and budget filters
- About section
- Real estate services
- Why Choose Us section
- Contact form with frontend validation
- Responsive mobile layout

**Technologies:** HTML5, CSS3, JavaScript

**Project Directory:** `business-landing-page/`

**Live Demo:** [Open EstateVista](https://kanav2401.github.io/-week1-assignments/business-landing-page/)

## Assignment 3: CSS Challenge – CSS Playground

A practical CSS project demonstrating modern layout systems, responsive design, and animation techniques.

### Features

**Flexbox Layout**
- Three testimonial cards in a horizontal desktop layout
- Vertical card arrangement on mobile
- Flexible widths, alignment, and spacing
- Card hover effects

**CSS Grid Layout**
- Six feature cards
- Responsive three-column desktop layout
- Two-column tablet layout
- Single-column mobile layout

**CSS Animations**
- Button hover animation
- CSS loading spinner
- Card lift effect
- Fade-in content reveal
- Smooth transitions and transformations

**Technologies:** HTML5, CSS3

**Project Directory:** `css-challenge/`

**Live Demo:** [Open CSS Playground](https://kanav2401.github.io/-week1-assignments/css-challenge/)

## How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/kanav2401/-week1-assignments.git
   ```

2. Open the downloaded repository in Visual Studio Code.
3. Select the project folder you want to run.
4. Open its `index.html` file using the Live Server extension.
5. View the website in your browser.

Each project can be run independently.
