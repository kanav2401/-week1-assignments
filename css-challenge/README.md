# CSS Playground – Flexbox, Grid and Animation Challenge

## Project Overview

CSS Playground is a practical frontend project developed as part of the WeIntern Web Development Internship – Week 1 Assignment.

The project demonstrates CSS layout techniques, responsive design principles, and modern animation effects through three focused exercises:

1. Flexbox Layout
2. CSS Grid Layout
3. CSS Animation Showcase

The objective is to demonstrate practical understanding of CSS properties, responsive breakpoints, alignment, spacing, transitions, transforms, and keyframe animations.

## Challenge 1: Flexbox Layout

A responsive testimonial section containing three customer review cards.

### Features
- Three cards arranged horizontally on desktop
- Vertical card arrangement on mobile
- Flexible card widths
- Consistent spacing and alignment
- Use of `display: flex`
- Use of `justify-content`, `align-items`, and `gap`
- Card hover interactions

## Challenge 2: CSS Grid Layout

A feature-card section demonstrating two-dimensional CSS Grid layouts.

### Features
- Six feature cards
- Three-column desktop layout
- Two-column tablet layout
- Single-column mobile layout
- Responsive grid sizing using `repeat()`
- Consistent card styling and spacing

## Challenge 3: CSS Animation Showcase

A collection of subtle animation effects demonstrating CSS transitions, transforms, and keyframes.

### Implemented Animations
- Button hover animation
- Rotating loading spinner
- Card lift effect
- Fade-in content reveal

### Animation Techniques
- `transition`
- `transform`
- `@keyframes`
- `animation`
- Hover interaction effects

## Responsive Design

The project supports desktop, tablet, and mobile screen sizes.

- Desktop: Three-column feature grid
- Tablet: Two-column feature grid
- Mobile: Single-column feature grid
- Responsive testimonial and animation sections
