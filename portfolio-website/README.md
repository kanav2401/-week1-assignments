# Professional Portfolio Website

## Project Overview

This project is a personal portfolio website developed as part of the WeIntern Web Development Internship – Week 1 Assignment.

The website showcases my professional introduction, technical skills, development projects, and contact information through a clean and responsive interface.

## Live Demo

[Visit Portfolio Website](https://kanav2401.github.io/-week1-assignments/portfolio-website/)

## GitHub Repository

[View Complete Source Code](https://github.com/kanav2401/-week1-assignments/tree/main/portfolio-website)

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

### Home Page
- Professional introduction and hero section
- Navigation to other portfolio pages
- Project highlights

### About Page
- Personal and professional introduction
- Career interests and background
- Technical skills and technologies

### Projects Page
- Showcase of development projects
- Project descriptions and relevant details

### Contact Page
- Contact information
- Contact form with frontend validation

### Additional Features
- Responsive desktop, tablet, and mobile layouts
- Dark and light theme toggle
- Interactive navigation menu
- Consistent typography and color scheme
- Smooth navigation and user interactions

## How to Run Locally

1. Clone the main repository:

   ```bash
   git clone https://github.com/kanav2401/-week1-assignments.git
   ```

2. Open the `portfolio-website` folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. View the portfolio in your browser.
